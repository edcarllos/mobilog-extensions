# Pontos críticos · Hot spots

Mostra onde o trânsito está mais lento agora: os trechos numerados no mapa, uma lista que leva o mapa até cada um e a lentidão da rede ao longo do tempo.

Shows where traffic is slowest right now: the stretches numbered on the map, a list that takes the map to each one, and the slowness of the network over time.
